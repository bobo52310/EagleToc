Smart TOC Copy Link Feature Test

測試說明: 本頁面用於測試 Smart TOC 的複製連結功能。將滑鼠移到 TOC 中的標題項目上，應該會看到一個連結符號(🔗)出現在右側。

開始使用

Smart TOC 是一個強大的瀏覽器擴充功能，能夠自動為網頁生成目錄導覽。

新功能: 現在您可以點擊每個標題項目旁邊的連結符號來複製該標題的直接連結！

安裝指南

安裝 Smart TOC 非常簡單，只需要從 Chrome 網路商店下載即可。

系統需求

Smart TOC 支援所有現代瀏覽器，包括 Chrome、Firefox 和 Edge。

功能概覽

Smart TOC 提供了豐富的功能來改善您的網頁閱讀體驗。

自動偵測

擴充功能會自動偵測頁面中的標題元素，並建立對應的目錄結構。

內容解析

Smart TOC 使用先進的演算法來識別和解析網頁內容結構。

標題提取

系統會自動提取 H1 到 H6 的所有標題元素。

互動式導覽

點擊目錄中的任何項目都會平滑捲動到對應的段落。

平滑捲動

使用先進的平滑捲動技術，提供最佳的使用者體驗。

自訂選項

Smart TOC 提供多種自訂選項，讓您能夠根據個人喜好調整功能。

主題選擇

選擇不同的主題來配合網站的視覺設計。

淺色主題

適合在明亮環境下使用的淺色主題。

深色主題

適合在昏暗環境下使用的深色主題。

位置設定

自由拖曳 TOC 面板到您喜歡的位置。

進階功能

探索 Smart TOC 的進階功能，提升您的生產力。

搜尋功能

使用內建的搜尋功能快速找到特定的標題。

鍵盤快速鍵

使用鍵盤快速鍵來快速操作 TOC 功能。

測試步驟:
  1. 手動載入 Smart TOC 或安裝擴充功能
  2. 開啟 TOC 面板
  3. 將滑鼠移到任何標題項目上
  4. 點擊出現的 🔗 符號
  5. 檢查是否成功複製連結並顯示回饋訊息
