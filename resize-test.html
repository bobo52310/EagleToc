🔄 多方向調整大小測試

功能說明：Smart TOC 浮動視窗現在支援從上下左右所有方向調整大小

測試步驟：

  1. 點擊瀏覽器工具列的 Smart TOC 圖示開啟目錄面板
  2. 將滑鼠移動到面板的邊緣和角落，觀察游標變化
  3. 嘗試從每個方向拖曳調整大小
  4. 測試所有8個調整點（4個角落 + 4個邊緣）
  5. 確認調整大小時面板位置和尺寸都正確

測試內容區域

以下內容用於生成足夠的目錄項目進行測試。

1. 基本調整大小測試

測試從右下角調整大小（原有功能）。

1.1 寬度調整

向右拖曳應該增加寬度。

1.2 高度調整

向下拖曳應該增加高度。

2. 邊緣調整測試

測試從四個邊緣調整大小。

2.1 右邊緣調整

只改變寬度，不影響高度和位置。

2.2 左邊緣調整

改變寬度和水平位置，不影響高度。

2.3 上邊緣調整

改變高度和垂直位置，不影響寬度。

2.4 下邊緣調整

只改變高度，不影響寬度和位置。

3. 角落調整測試

測試從四個角落調整大小。

3.1 右下角（原功能）

同時改變寬度和高度，位置不變。

3.2 右上角

改變寬度、高度和垂直位置。

3.3 左下角

改變寬度、高度和水平位置。

3.4 左上角

改變寬度、高度、水平位置和垂直位置。

4. 限制測試

測試調整大小的限制。

4.1 最小尺寸

最小寬度：250px，最小高度：200px。

4.2 最大尺寸

最大寬度：80% 螢幕寬度，最大高度：80% 螢幕高度。

4.3 邊界限制

調整大小時不應超出螢幕範圍。

5. 互動測試

測試調整大小與其他功能的互動。

5.1 拖曳與調整大小

確認拖曳標題列不會觸發調整大小。

5.2 摺疊狀態

摺疊時調整大小手柄應該隱藏。

5.3 設定面板

調整大小時設定面板應該正常運作。

6. 視覺回饋測試

6.1 游標變化

滑鼠移到不同調整手柄時游標應該正確變化。

6.2 手柄可見性

調整手柄在 hover 時應該更明顯。

6.3 調整中狀態

調整大小時面板應該有適當的視覺回饋。

測試完成清單

請確認以下所有項目都正常工作：

  • ✅ 8個調整手柄都可見且可用
  • ✅ 游標在不同手柄上正確變化
  • ✅ 邊緣調整只影響對應方向
  • ✅ 角落調整影響兩個方向
  • ✅ 左側/上方調整會移動面板位置
  • ✅ 最小/最大尺寸限制生效
  • ✅ 摺疊時手柄隱藏
  • ✅ 不影響其他功能運作
