🔧 技術實現詳解

版本 1：基本實現

// 基本滾動事件監聽器 const scrollListener = () => { const scrollTop = window.pageYOffset; const windowHeight = window.innerHeight; // 遍歷所有標題，計算距離 let activeHeading = null; let minDistance = Infinity; headings.forEach(heading => { const rect = heading.element.getBoundingClientRect(); const distance = Math.abs(rect.top - offset); if (distance < minDistance) { minDistance = distance; activeHeading = heading; } }); // 直接更新活動標題 if (activeHeading) setActiveHeading(activeHeading.id); }; window.addEventListener('scroll', scrollListener);

版本 2：增強實現

// 防抖 + 視覺反饋的滾動處理 const enhancedScrollListener = () => { // 立即反饋 isScrolling = true; addScrollingVisualFeedback(); updateActiveHeadingImmediate(); // 防抖處理 clearTimeout(scrollTimeout); scrollTimeout = setTimeout(() => { isScrolling = false; removeScrollingVisualFeedback(); // 最終確認 updateActiveHeadingWithAnimation(); }, 150); }; // 平滑滾動到活動項目 tocContent.scrollTo({ top: idealScroll, behavior: 'smooth' });

版本 3：智能實現

// 雙重 Intersection Observer 智能檢測 const primaryObserver = new IntersectionObserver((entries) => { entries.forEach(entry => { const scores = confidenceScores.get(entry.target.id); // 多維度評分 scores.visibility = entry.intersectionRatio; scores.position = calculatePositionScore(entry); scores.stability = updateStabilityScore(scores); scores.userIntent = analyzeUserIntent(entry); // 綜合評分算法 const totalScore = ( scores.visibility * 0.4 + scores.position * 0.3 + scores.stability * 0.15 + scores.userIntent * 0.15 ); // 高置信度才更新 if (totalScore > 0.6) { setActiveHeadingWithConfidence(entry.target.id, totalScore); } }); }, adaptiveOptions);

📸 截圖生成指南

為了完整展示三個版本的差異，請按照以下步驟生成對比截圖：

步驟 1：環境準備

確保已經創建並配置好三個 Git Worktree 環境。每個環境都有獨立的代碼版本和功能實現。

# 檢查 worktree 狀態 git worktree list # 應該看到三個環境： # smart-toc-v1-basic-scroll (scroll-sync-v1) # smart-toc-v2-enhanced-scroll (scroll-sync-v2) # smart-toc-v3-smart-scroll (scroll-sync-v3)

步驟 2：瀏覽器設置

準備三個不同的 Chrome 瀏覽器窗口或用戶配置檔，分別載入三個版本的擴展：

  • 瀏覽器 1：載入版本 1 擴展（basic-scroll）
  • 瀏覽器 2：載入版本 2 擴展（enhanced-scroll）
  • 瀏覽器 3：載入版本 3 擴展（smart-scroll）

步驟 3：測試頁面準備

在每個瀏覽器中開啟測試頁面：

# 開啟測試頁面 file:///path/to/smart-toc/scroll-sync-test.html # 或者使用本地服務器 python -m http.server 8000 # 然後訪問 http://localhost:8000/scroll-sync-test.html

步驟 4：截圖場景

為每個版本拍攝以下場景的截圖：

  • 初始狀態：頁面剛載入時的 TOC 面板狀態
  • 滾動中：正在滾動時的視覺反饋效果
  • 活動高亮：不同標題被激活時的高亮效果
  • 過渡動畫：標題切換時的動畫效果（如果有）
  • 特殊狀態：版本特有的視覺指示器

步驟 5：對比截圖

建議的截圖命名規範：

v1-basic-initial.png # 版本1初始狀態 v1-basic-scrolling.png # 版本1滾動中 v1-basic-active.png # 版本1活動高亮 v2-enhanced-initial.png # 版本2初始狀態 v2-enhanced-scrolling.png # 版本2滾動反饋 v2-enhanced-animation.png # 版本2動畫效果 v3-smart-initial.png # 版本3初始狀態 v3-smart-confidence.png # 版本3置信度指示 v3-smart-prediction.png # 版本3智能預測

步驟 6：自動化截圖腳本（可選）

可以使用 Playwright 或 Puppeteer 創建自動化截圖腳本：

// 示例 Playwright 腳本 const { chromium } = require('playwright'); async function captureScreenshots() { const browser = await chromium.launch(); const page = await browser.newPage(); // 載入擴展和測試頁面 await page.goto('file:///path/to/scroll-sync-test.html'); // 等待 TOC 載入 await page.waitForSelector('.smart-toc-panel'); // 截圖初始狀態 await page.screenshot({ path: 'v1-basic-initial.png' }); // 模擬滾動並截圖 await page.evaluate(() => window.scrollTo(0, 1000)); await page.waitForTimeout(500); await page.screenshot({ path: 'v1-basic-scrolling.png' }); await browser.close(); }

🚀 快速測試腳本

以下腳本可以幫助快速切換和測試不同版本：

#!/bin/bash # quick-test.sh - 快速版本測試腳本 echo "🔄 Smart TOC 版本切換工具" case $1 in 1) echo "📌 切換到版本 1：基本滾動同步" cd ../smart-toc-v1-basic-scroll ;; 2) echo "📌 切換到版本 2：增強滾動同步" cd ../smart-toc-v2-enhanced-scroll ;; 3) echo "📌 切換到版本 3：智能滾動同步" cd ../smart-toc-v3-smart-scroll ;; *) echo "使用方法: ./quick-test.sh [1|2|3]" echo " 1 - 版本1：基本實現" echo " 2 - 版本2：增強體驗" echo " 3 - 版本3：智能同步" exit 1 ;; esac echo "📂 當前目錄: $(pwd)" echo "🌿 當前分支: $(git branch --show-current)" echo "✅ 版本切換完成！"
