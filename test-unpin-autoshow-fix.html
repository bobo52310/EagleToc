Smart TOC Unpin 自動顯示修復測試

🎯 測試目標

驗證 unpin 後能永久阻止自動顯示，即使開啟了全域 autoShow 設定也不會自動顯示。

🔧 修復版本：v3.1 - 添加排除列表機制，解決 autoShow 全域設定覆蓋 unpin 的問題

🆕 新功能：排除列表機制

  • 排除列表優先級最高：即使全域 autoShow 開啟，被 unpin 的網站也不會自動顯示
  • 智能管理：unpin 時自動加入排除列表，重新 pin 時自動移除
  • 持久記憶：用戶的明確意圖被永久記住，直到重新加入白名單

🔄 新的自動顯示優先級邏輯

  1. 第一優先級：檢查排除列表 → 如果在列表中，絕對不自動顯示
  2. 第二優先級：檢查白名單 → 如果在白名單中，自動顯示
  3. 第三優先級：檢查全域設定 → 如果 autoShow 開啟，自動顯示

這確保了用戶明確 unpin 的決定永遠被尊重！

🧪 測試步驟

  1. 準備階段：
    • 確認當前網域不在白名單中
    • （可選）在設定中開啟全域 autoShow，增加測試嚴格度
  2. Pin 測試：
    • 手動開啟 Smart TOC
    • 點擊 📌 按鈕加入白名單
    • 確認看到「已將 xxx 加入白名單」通知
    • 觀察按鈕變為 📍
  3. Unpin 測試：
    • 點擊 📍 按鈕移除白名單
    • 確認看到「已從白名單移除 xxx」通知
    • 觀察按鈕變回 📌
    • 關鍵：檢查 Console 有「Added xxx to excluded list」
  4. 重新載入測試：
    • 關閉 TOC 面板
    • 重新載入頁面
    • 觀察：TOC 應該 絕對不會 自動顯示
    • 即使全域 autoShow 開啟也不應該顯示
  5. 重新 Pin 測試：
    • 手動開啟 TOC，重新點擊 📌 加入白名單
    • 確認 Console 有「Removed xxx from excluded list」
    • 重新載入頁面，確認恢復自動顯示

✅ 成功標準

  • 絕對阻止：unpin 後絕對不自動顯示，即使開啟全域 autoShow
  • 排除列表管理：unpin 時加入排除列表，重新 pin 時移除
  • 持久效果：重新載入、關閉瀏覽器後效果持續
  • 可逆操作：重新 pin 能恢復正常自動顯示功能

🔍 調試信息

關鍵的 Console 日誌信息：

  • 🚫 Domain is in excluded list (user explicitly unpinned), blocking auto show
  • 🚫 Added [domain] to excluded list
  • ✅ Removed [domain] from excluded list (re-added to whitelist)
  • 🚫 Checking excluded list for domain: [domain]

手動檢查指令：

// 檢查當前域名是否在排除列表中 window.smartTOC.isInExcludedList(window.location.hostname) // 查看完整的排除列表 window.smartTOC.settings.excludedDomains // 檢查自動顯示邏輯 window.smartTOC.shouldAutoShowBySettings() // 手動觸發自動顯示檢查 window.smartTOC.checkAutoShow()

技術實作說明

🔧 核心修改

  • 新增設定項目：
    • excludedDomains: [] - 儲存用戶明確 unpin 的域名
  • 新增方法：
    • isInExcludedList(domain) - 檢查域名是否在排除列表
    • addToExcludedList(domain) - 添加域名到排除列表
    • removeFromExcludedList(domain) - 從排除列表移除域名
  • 修改邏輯：
    • shouldAutoShowBySettings() - 排除列表檢查為第一優先級
    • removeFromWhitelist() - 成功後自動加入排除列表
    • addToWhitelist() - 成功後自動從排除列表移除

📋 解決的問題

  • 原問題：全域 autoShow 設定會覆蓋用戶的 unpin 決定
  • 解決方案：排除列表機制確保用戶明確意圖被永久記住
  • 用戶體驗：unpin 真正意味著「我不想在這個網站自動顯示」

預期行為

🎯 完整流程

  1. 初次載入：檢查排除列表 → 白名單 → 全域設定
  2. 用戶 pin：加入白名單 + 從排除列表移除
  3. 用戶 unpin：從白名單移除 + 加入排除列表
  4. 重新載入：排除列表阻止自動顯示

🔄 狀態管理

系統維護三個狀態列表：

  • autoShowWhitelist：允許自動顯示的域名
  • excludedDomains：用戶明確拒絕自動顯示的域名
  • autoShow (全域)：全局自動顯示開關

排除列表的優先級永遠最高！
