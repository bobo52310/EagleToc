階層深度切換功能測試 H1

測試說明

  1. 點擊瀏覽器工具列的 Smart TOC 圖標開啟目錄面板
  2. 觀察面板左上方的深度控制器：[-] H3 [+]（預設顯示到 H3 層級）
  3. 點擊 [+] 按鈕增加深度：H3 → H4 → H5 → H6（到達 H6 後按鈕變灰禁用）
  4. 點擊 [-] 按鈕減少深度：H6 → H5 → H4 → H3 → H2 → H1（到達 H1 後按鈕變灰禁用）
  5. 每次點擊後，目錄應即時更新顯示對應深度的標題
  6. 測試邊界情況：H1 時減少按鈕禁用，H6 時增加按鈕禁用
深度等級說明：
  • H1：只顯示最頂層標題（章節）
  • H2：顯示到第二層標題（章節 + 主要段落）
  • H3：顯示到第三層標題（預設設定，適合大多數文章）
  • H4-H6：顯示更深層次的標題（適合詳細文檔）

結論

透過這個測試頁面，您可以完整測試 Smart TOC 的階層深度切換功能。使用遞增/遞減按鈕時應該能看到：

  • 即時更新：目錄內容立即反映新的深度設定
  • 精確控制：使用 [+] 和 [-] 按鈕精確控制深度層級
  • 邊界保護：到達 H1 或 H6 時對應按鈕自動禁用
  • 視覺回饋：中央顯示當前深度等級，按鈕狀態即時更新
  • 設定保存：重新開啟面板時記住上次的深度設定
  • 操作直觀：不再需要記住循環順序，想要什麼深度直接點擊對應方向
