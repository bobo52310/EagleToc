Smart TOC Pin 白名單功能測試

📌 新功能說明

這個測試頁面用來驗證新的 Pin 白名單功能。現在您可以直接在工具列使用 📌 按鈕來管理白名單，而不需要在設定面板中操作。

🧪 測試步驟 (全面修復版本 v3.0)

  1. 開啟 TOC：點擊擴充套件圖示開啟 Smart TOC
  2. 查看釘選按鈕：找到工具列中的 📌 按鈕
  3. 測試釘選功能：點擊 📌 按鈕來切換白名單狀態
  4. 觀察狀態變化：
    • 按鈕狀態應該立即反映變化（未釘選 📌 / 已釘選 📍）
    • 應該看到成功/失敗的通知訊息
  5. 檢查 Console 日誌：開啟開發者工具查看詳細的診斷訊息
  6. 驗證持久性：重新載入頁面，確認設定被正確保存
  7. 測試錯誤恢復：如果出現錯誤，系統應該自動重試並提供詳細錯誤信息

✅ 完整修復內容 (v3.0 - 儲存系統重構)

  • 🔧 儲存系統重構：
    • 分離白名單儲存邏輯，避免超過 Chrome storage 限制
    • 添加重試機制（最多 3 次），提高儲存成功率
    • 智能錯誤恢復，自動回滾失敗的變更
  • 📊 儲存大小檢查：
    • 預檢查資料大小，防止超過 8KB 限制
    • 自動優化儲存策略
    • 提供詳細的儲存使用情況
  • 🛡️ 錯誤處理強化：
    • 詳細的錯誤日誌和診斷信息
    • 區分不同類型的錯誤原因
    • 用戶友好的錯誤提示
  • ✅ 域名驗證：添加域名格式驗證，防止無效域名造成問題
  • 🔄 自動重試機制：網路或暫時性錯誤時自動重試
  • 💾 優化儲存策略：支援分離式儲存和批次操作

功能測試區域

📌 Pin 按鈕功能 (v2.0)

全新的智能 Pin 系統提供完整的視覺回饋：

  • 智能按鈕狀態 - 按鈕圖示會根據當前頁面的白名單狀態自動變化
  • 動態選單文字 - 選單項目會顯示「新增」或「取消」，清楚表達當前可執行的操作
  • 📌/🔗 網域/URL 切換 - 可分別管理網域級別和 URL 級別的白名單
  • 即時狀態顯示 - 「當前設定」區域即時反映最新狀態

🎯 白名單邏輯

系統會智能判斷當前頁面的白名單狀態：

  • 如果當前 URL 已在白名單中，顯示 ✅ 此 URL 已加入白名單
  • 如果當前網域已在白名單中，顯示 ✅ 此網域已加入白名單
  • 如果都沒有，顯示「未加入白名單」

⚙️ 設定面板整合

設定面板中的白名單區塊已簡化為：

  • 顯示白名單項目數量
  • 提供「管理」按鈕查看所有白名單項目
  • 主要管理功能移至 📌 按鈕

🔍 診斷和調試

Console 日誌類型

修復後的版本提供詳細的診斷信息，請關注以下日誌：

  • 💾 Attempting to save settings - 開始儲存設定
  • 📤 Sending save-settings message - 發送儲存訊息
  • 📥 Received response from background - 收到背景回應
  • 📊 Storage size check - 儲存大小檢查
  • 🔄 Retrying - 重試機制啟動
  • ✅ Successfully added/removed - 操作成功
  • ❌ Failed - 操作失敗（含詳細原因）

常見問題診斷

如果仍然看到「加入失敗」：

  1. 檢查 Console：查看是否有 ❌ 開頭的錯誤訊息
  2. 儲存大小問題：看是否有 Storage limit exceeded 訊息
  3. 重試失敗：查看是否所有重試嘗試都失敗了
  4. Chrome 權限：確認擴充套件有 storage 權限
  5. 網路問題：暫時的網路中斷可能導致 Chrome runtime 通訊失敗

手動測試指令

在 Console 中執行以下指令來檢查狀態：

// 檢查當前白名單狀態
window.smartTOC.getWhitelistStorageInfo()

// 檢查當前設定
window.smartTOC.settings

// 手動測試保存
window.smartTOC.saveSettings()

問題回報

如果經過診斷後問題仍然存在，請提供以下信息：

  • 完整的 Console 錯誤訊息
  • 白名單大小信息（執行上述指令獲取）
  • Chrome 版本和作業系統
  • 是否在無痕模式下測試
  • 具體的錯誤重現步驟
