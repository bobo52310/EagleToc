📝 測試說明

測試目標：確認字體大小調整功能只影響 TOC 目錄列表，不影響工具列

  1. 點擊瀏覽器工具列的 Smart TOC 圖示開啟目錄面板
  2. 觀察目錄面板的工具列（標題、按鈕）字體大小
  3. 觀察目錄面板的目錄列表字體大小
  4. 點擊設定按鈕⚙️開啟設定面板
  5. 使用 + 按鈕增大字體，觀察：
    • ✅ 目錄列表字體應該變大
    • ✅ 工具列字體應該保持不變
    • ✅ 設定面板字體應該保持不變
  6. 使用 - 按鈕減小字體，觀察同樣的效果
  7. 測試字體大小範圍：12px 到 24px
