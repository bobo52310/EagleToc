🎯 測試重點

測試字體大小調整功能是否只影響目錄列表項目，不影響其他元素。

預期行為

目錄列表項目字體會隨 +/- 按鈕變化
工具列標題 "Table of Contents" 保持固定大小
按鈕圖示 ⚙️📁📂📋× 保持固定大小
設定面板文字保持固定大小
載入訊息 "Analyzing page structure..." 保持固定大小

避免的錯誤行為

工具列標題字體跟著變化
按鈕圖示大小跟著變化
設定面板字體跟著變化

測試用標題結構

以下標題將出現在 TOC 中，請測試它們的字體大小調整：

1. 第一級標題

這是最高層級的標題，在 TOC 中應該是粗體顯示。

1.1 第二級標題

第二層級標題，在 TOC 中會有適當縮排。

1.1.1 第三級標題

第三層級標題，字體應該較小且有更深的縮排。

1.2 另一個第二級標題

用於測試平行層級的顯示效果。

2. 字體大小測試章節

專門用來測試字體大小變化效果。

2.1 最小字體測試 (12px)

將字體調到最小時的顯示效果。

2.2 預設字體測試 (16px)

預設字體大小的顯示效果。

2.3 最大字體測試 (24px)

將字體調到最大時的顯示效果。

2.3.1 大字體子項目

測試大字體下的子項目縮排是否正確。

3. 測試步驟

請按照以下步驟進行測試：

3.1 開啟 TOC

點擊瀏覽器擴充功能圖示。

3.2 觀察初始狀態

注意工具列和目錄列表的字體大小。

3.3 開啟設定

點擊 ⚙️ 按鈕開啟設定面板。

3.4 調整字體

使用字體大小的 + 和 - 按鈕。

3.5 檢查結果

確認只有目錄項目的字體改變了。

4. 預期結果

4.1 目錄項目

這些項目的字體大小應該會變化：

  • "1. 第一級標題"
  • "1.1 第二級標題"
  • "1.1.1 第三級標題"
  • 等等所有目錄項目...

4.2 固定大小元素

這些元素的字體大小應該保持不變：

  • 工具列標題 "Table of Contents"
  • 所有按鈕圖示
  • 設定面板中的 "字體大小" 標籤
  • 設定面板中的 "高亮時間" 標籤
  • 載入訊息
