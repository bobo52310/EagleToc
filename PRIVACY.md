# Privacy Policy / 隱私政策

**Last updated: December 2025**

## English

### Data Collection
EagleToc does **not** collect, transmit, or share any personal data to remote servers.

### Local Storage
EagleToc stores the following data locally on your device:
- **User preferences**: Theme settings, panel position, font size, and other customization options are stored using Chrome's `chrome.storage.sync` API
- **Whitelist/Exclude list**: Domain patterns you configure for auto-show functionality
- **Zen Mode settings**: Reading preferences stored in browser localStorage

### Data Synchronization
When you are signed into Chrome, your settings may sync across your devices through Chrome's built-in sync feature. This is handled entirely by Chrome and not by EagleToc.

### Permissions Explanation
- **activeTab**: Required to access the current page URL for whitelist matching
- **storage**: Required to save your preferences
- **Host permissions (all URLs)**: Required to generate table of contents on any website you visit. The extension needs to read page headings to create the TOC.

### Third-Party Services
EagleToc does **not** use any analytics, tracking, or advertising services.

### Open Source
This extension is open source. You can review the complete source code on GitHub.

## 繁體中文

### 資料收集
EagleToc **不會**收集、傳輸或分享任何個人資料到遠端伺服器。

### 本機儲存
EagleToc 在您的裝置上本機儲存以下資料：
- **使用者偏好設定**：主題設定、面板位置、字體大小等自訂選項，使用 Chrome 的 `chrome.storage.sync` API 儲存
- **白名單/排除清單**：您設定的自動顯示網域模式
- **禪讀模式設定**：閱讀偏好設定儲存在瀏覽器 localStorage

### 資料同步
當您登入 Chrome 時，您的設定可能會透過 Chrome 內建的同步功能在您的裝置間同步。這完全由 Chrome 處理，而非 EagleToc。

### 權限說明
- **activeTab**：用於存取當前頁面 URL 以進行白名單比對
- **storage**：用於儲存您的偏好設定
- **主機權限（所有 URL）**：用於在您造訪的任何網站上產生目錄。擴充功能需要讀取頁面標題來建立目錄。

### 第三方服務
EagleToc **不使用**任何分析、追蹤或廣告服務。

### 開源
此擴充功能為開源軟體。您可以在 GitHub 上查看完整原始碼。
