🧪 字體大小工具列控制測試

本頁面用於測試 Smart TOC 的字體大小調整功能，新增的工具列控制項包括：

  • 減小字體按鈕：使用 SVG 圖示，點擊可減小字體
  • 字體大小顯示：顯示當前字體大小（如：16px）
  • 增大字體按鈕：使用 SVG 圖示，點擊可增大字體

這些控制項位於深度控制項和操作按鈕之間，具有獨特的綠色主題樣式。

🔍 測試步驟

  1. 開啟 Smart TOC 面板
  2. 在工具列中找到字體大小控制項（綠色背景，位於深度控制項旁邊）
  3. 點擊 減小字體 按鈕，觀察：
    • TOC 內容字體是否變小
    • 工具列顯示的字體大小數字是否更新
    • 設定模態框中的字體大小是否同步更新
  4. 點擊 增大字體 按鈕，觀察相同項目
  5. 測試字體大小邊界值（12px 最小，24px 最大）
  6. 確認工具列控制項與設定模態框中的控制項同步運作

第一章：智慧目錄系統

智慧目錄（Smart TOC）是一個強大的網頁導航工具，能夠自動分析頁面結構並生成可互動的目錄。本章將介紹其核心功能和使用方法。

1.1 基本功能

Smart TOC 提供了多種實用功能，包括自動標題檢測、主題切換、搜尋功能等。使用者可以透過簡潔的介面快速導航至任何標題位置。

1.1.1 標題層級管理

系統支援 H1 到 H6 的所有標題層級，並提供層級深度控制功能。使用者可以根據需要調整顯示的標題深度。

深度控制的好處

通過調整顯示深度，使用者可以：

  • 專注於主要章節（顯示 H1-H2）
  • 查看詳細結構（顯示 H1-H6）
  • 自訂適合的導航層級
實際應用場景

在閱讀技術文件時，使用者通常需要先了解整體架構，然後逐步深入細節。深度控制功能使這個過程變得更加順暢。

細節說明

每個標題都會被自動分配唯一的 ID，確保導航的準確性和可靠性。

1.2 字體大小調整

新增的字體大小調整功能允許使用者：

// 字體大小控制邏輯 const newSize = Math.max(12, Math.min(24, currentSize + delta)); if (newSize !== currentSize) { updateFontSize(newSize); updateDisplay(newSize + 'px'); }

1.2.1 工具列整合

字體控制項直接整合在主工具列中，提供即時調整功能，無需開啟設定面板。這大大提升了使用體驗。

設計考量

控制項使用綠色主題以區別於其他功能，並採用直觀的 SVG 圖示設計。

1.2.2 同步機制

工具列控制項與設定模態框完全同步，確保一致的使用體驗。

1.3 主題系統

Smart TOC 支援多種視覺主題，包括自動適應、亮色、深色等多種選項。

1.3.1 自動主題偵測

系統能夠自動偵測網頁的背景色彩，並選擇最適合的對比主題。

色彩分析演算法

透過分析網頁的背景色彩和文字色彩，系統可以選擇最佳的顯示主題。

1.4 搜尋功能

內建的搜尋功能支援即時過濾和高亮顯示，幫助使用者快速找到目標內容。

1.4.1 即時搜尋

使用者輸入關鍵字時，系統會即時過濾符合條件的標題。

搜尋演算法

採用模糊匹配演算法，即使輸入不完整的關鍵字也能找到相關標題。

性能最佳化

搜尋功能經過最佳化，即使在包含大量標題的頁面上也能保持流暢的回應速度。
