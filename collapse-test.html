🐛 問題描述

問題：點擊收合按鈕（📁）後，視窗內容變空白但大小不變

預期行為：視窗應該只保留標題列，高度自動調整為最小

🔧 修復內容

已修復收合狀態的CSS，強制重置最小高度限制：

  • min-height: 0 !important - 移除200px最小高度限制
  • height: auto !important - 允許高度自動調整
  • overflow: visible - 確保內容正確顯示

✅ 預期的正確行為

步驟 1：開啟 TOC 面板 → 應該顯示完整的目錄列表
步驟 2：點擊📁收合按鈕 → 面板高度縮小，只顯示標題列
步驟 3：點擊📂展開按鈕 → 面板恢復原始大小，顯示完整內容
步驟 4：收合狀態下調整大小手柄應該隱藏

測試標題結構

以下內容用於生成足夠的目錄項目，方便測試收合/展開效果。

1. 收合功能基本測試

測試基本的收合和展開功能。

1.1 收合狀態檢查

收合後應該：

  • 內容區域完全隱藏
  • 面板高度自動縮小到只有標題列
  • 收合按鈕（📁）隱藏
  • 展開按鈕（📂）顯示
  • 調整大小手柄隱藏

1.2 展開狀態檢查

展開後應該：

  • 內容區域完全顯示
  • 面板恢復到收合前的大小
  • 展開按鈕（📂）隱藏
  • 收合按鈕（📁）顯示
  • 調整大小手柄顯示

2. 互動功能測試

2.1 拖曳功能

收合狀態下，拖曳標題列應該仍然可以移動面板位置。

2.2 其他按鈕

收合狀態下，其他按鈕（設定、複製、關閉）應該仍然可用。

2.3 鍵盤快捷鍵

Escape 和 Alt+T 快捷鍵應該仍然有效。

3. 視覺效果測試

3.1 動畫效果

收合和展開應該有平滑的過渡動畫。

3.2 按鈕狀態

按鈕圖示應該正確切換（📁 ↔ 📂）。

3.3 內容保持

展開後內容應該與收合前完全相同。

4. 邊界情況測試

4.1 快速切換

快速點擊收合/展開按鈕應該正常工作。

4.2 調整大小後收合

手動調整大小後，收合和展開應該正常工作。

4.3 位置移動後收合

拖曳移動位置後，收合和展開應該正常工作。

5. 測試步驟總結

  1. 開啟 Smart TOC 擴充功能
  2. 觀察初始狀態（應顯示完整內容）
  3. 點擊📁收合按鈕
  4. 檢查面板是否正確縮小
  5. 點擊📂展開按鈕
  6. 檢查面板是否正確恢復
  7. 重複測試確保功能穩定
