⚙️ 個性化設置系統

🎛️ 全方位自訂控制

版本3提供完整的設置面板，讓您可以精確調整每一個細節，打造最符合個人喜好的閱讀環境。

📏 字體大小調整

16px - 72px 範圍內自由調整，適應不同螢幕尺寸和閱讀習慣。滑桿控制提供即時預覽效果。

📐 行距控制

40px - 120px 行距調整，優化文字可讀性。合適的行距能顯著提升長時間閱讀的舒適度。

🌫️ 背景模糊程度

0 - 50px 模糊效果，控制背景的清晰度。較高的模糊值能增強專注度，降低背景干擾。

💾 智能設置記憶

所有個人化設置都會自動保存到瀏覽器本地儲存，下次使用時會自動載入您的偏好設定，無需重新調整。

🔄 實時預覽系統

所有設置調整都會即時反映在 Zen Mode 中，您可以邊調整邊觀察效果，找到最完美的配置組合。
