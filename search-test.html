Smart TOC 搜尋功能測試頁面

測試說明：
  1. 點擊瀏覽器的 Smart TOC 擴充功能按鈕啟動 TOC
  2. 點擊 TOC 面板中的 🔍 搜尋按鈕，或使用快捷鍵 Ctrl/Cmd + K 開啟搜尋視窗
  3. 嘗試以下搜尋範例來測試模糊比對功能
  4. 使用鍵盤 ↑↓ 鍵導航搜尋結果，Enter 鍵選擇
搜尋測試範例：
  • intro - 應該匹配 "Introduction" 等標題
  • js - 應該匹配包含 "JavaScript" 的標題
  • api - 應該匹配所有包含 "API" 的標題
  • test - 應該匹配所有測試相關標題
  • 功能 - 應該匹配中文標題
  • ug - 測試字元跳躍匹配 (User Guide)
鍵盤快捷鍵測試：
  • Ctrl/Cmd + K - 開啟搜尋模態視窗（全域快捷鍵）
  • Alt + S - 開啟搜尋視窗（TOC 開啟時）
  • ↑/↓ - 在搜尋結果中導航
  • Enter - 選擇當前搜尋結果
  • ESC - 關閉搜尋視窗或 TOC

搜尋功能測試結果

使用上述搜尋範例測試後，應該能夠：

  • ✓ Alfred/Raycast 風格：置中的搜尋模態視窗
  • ✓ 部分字元匹配：輸入 "intro" 找到 "Introduction"
  • ✓ 忽略大小寫：輸入 "api" 找到 "API Documentation"
  • ✓ 中文搜尋：輸入 "功能" 找到相關中文標題
  • ✓ 模糊匹配：輸入 "js" 找到 "JavaScript" 相關標題
  • ✓ 字元跳躍：輸入 "ug" 找到 "User Guide"
  • ✓ 鍵盤導航：↑↓ 鍵選擇結果，Enter 跳轉
  • ✓ 高亮顯示：匹配的文字會被高亮標示
  • ✓ 即時搜尋：輸入時立即顯示結果
  • ✓ 平滑動畫：模態視窗開啟/關閉動畫效果
