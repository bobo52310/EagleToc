# 🦅 EagleToc - 鷹眼智慧目錄
*鷹眼俯瞰，精準導航*

一款專為提升網頁閱讀體驗而設計的 Chrome 擴充功能，如老鷹般敏銳地自動為任何網站生成智慧目錄，讓您以鷹眼視角俯瞰全文結構，精準導航長篇文章、技術文件和線上書籍。

## ✨ 核心特色

### 🦅 **鷹眼智慧偵測**
如老鷹般敏銳，自動識別頁面結構和標題層級，無需手動設定

### 🎯 **精準定位導航**
高空俯瞰全文架構，精準定位當前閱讀位置，一鍵跳轉至任意段落

### 🎪 **靈活浮動面板**
可拖拉、縮放、停靠的智慧面板，如鷹翼般優雅，不干擾閱讀體驗

### 🌙 **多主題切換**
支援亮色、暗色主題，以及海洋、森林等個性化主題，適應各種閱讀環境

### 🧘 **禪讀模式**
沈浸式閱讀體驗，如鷹眼專注獵物般專注文字內容，消除干擾

### ⚡ **智慧白名單**
支援 `*.github.*` 等彈性網域設定，智慧自動啟動，如鷹眼識別目標

### 🔍 **快速搜尋定位**
即時搜尋標題內容，快速跳轉至目標段落，精準如鷹擊

### 📋 **多格式匯出**
支援純文字、Markdown 格式複製，便於筆記整理和知識管理

## 📥 安裝方式

### 🏪 從 Chrome 擴充商店安裝
*即將上線，敬請期待*

### 🔧 手動安裝（開發者模式）

1. **下載擴充功能**
   ```bash
   git clone https://github.com/bobo52310/EagleToc.git
   ```

2. **開啟 Chrome 擴充功能頁面**
   - 前往 `chrome://extensions/`
   - 開啟右上角的「開發人員模式」

3. **載入擴充功能**
   - 點選「載入未封裝項目」
   - 選擇下載的 eagle-toc 資料夾
   - EagleToc 將出現在清單中，準備展翅高飛！

## 📱 使用說明

### 基本操作
1. **📖 開啟目錄**：點選工具列的擴充功能圖示
2. **🎯 快速導航**：點選任意標題即可跳轉至對應段落
3. **❌ 關閉面板**：點選 × 按鈕或按 Escape 鍵
4. **📐 調整大小**：拖拉右下角調整面板尺寸
5. **🚀 移動位置**：拖拉標題列重新定位面板

### 快捷鍵
- **Escape**：關閉目錄面板
- **Alt/Option + 懸停**：快速預覽模式

### 個人化設定
透過擴充功能圖示 → 設定按鈕存取：
- ✅ 啟用本機 HTML 檔案支援
- 🤖 相容頁面自動顯示目錄
- 📊 最大標題層級設定（3-6層）
- 📍 目錄位置和寬度調整
 - 🧩 自動顯示白名單與隱藏站點清單（支援萬用字元）
 - 🧷 浮動模式可拖曳面板位置並自動記憶（提供「重設位置」）

## 🎨 主題和個性化

### 🌈 **多樣主題選擇**
- **🌞 亮色主題**：清新簡潔，適合日間閱讀
- **🌙 暗色主題**：護眼舒適，適合夜間使用
- **🌊 海洋主題**：藍色系，營造寧靜氛圍
- **🌲 森林主題**：綠色系，自然清新
- **🌅 夕陽主題**：暖色系，溫馨愜意
- **🌌 銀河主題**：夢幻色彩，科技感十足

### 🧘 **禪讀模式特色**
- **沈浸式體驗**：全螢幕閱讀，專注內容
- **背景模糊**：淡化干擾元素
- **多種速度控制**：慢、中、快三檔滾動
- **進度追蹤**：顯示閱讀進度
- **個性化設定**：字體大小、行距、模糊程度

## 🏆 技術優勢

### 🎯 **核心技術**
- **智慧演算法**：自動偵測文章結構和標題層級
- **效能優化**：僅在需要時執行，不影響頁面載入速度
- **跨網站相容**：適用於任何使用標準 HTML 標題標籤的網站
- **響應式設計**：自動適應不同螢幕尺寸

### 🔒 **隱私保護**
- **本機處理**：所有功能在本機執行，不傳送資料
- **最小權限**：僅要求必要的瀏覽權限
- **無追蹤**：不收集使用者行為資料
