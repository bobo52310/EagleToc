🎨 Smart TOC 主題切換功能測試

驗證快速主題切換的各種操作方式和視覺效果

📋 測試說明

這個頁面用來測試 Smart TOC 的主題切換功能。確保 Smart TOC 擴充套件已啟用，然後按照以下說明進行測試。

🚀 測試步驟

1
確認 Smart TOC 面板已顯示在頁面右側
2
在工具列中找到 🎨 主題按鈕
3
測試不同的切換方式（見下方詳細說明）
4
觀察主題切換的視覺效果和過渡動畫

🎯 主題切換方式

💫 快速切換（推薦）

單擊主題按鈕 🎨 - 循環切換所有主題

順序：自動適應 → 亮色 → 深色 → 海洋 → 森林 → 日落 → 珊瑚 → 自動適應...

⌨️ 鍵盤快捷鍵

按下 Alt + T 快速切換主題

適合頻繁切換或無法使用滑鼠的情況

📋 精確選擇

右鍵點擊主題按鈕 或 長按 0.5 秒 顯示主題選單

可以直接選擇特定主題，適合有明確目標的切換

🔍 測試要點

功能測試

  • ✅ 單擊主題按鈕是否能循環切換主題
  • ✅ 鍵盤快捷鍵 Alt+T 是否正常工作
  • ✅ 右鍵或長按是否顯示主題選單
  • ✅ 主題選單中的選項是否可點擊
  • ✅ 當前主題在選單中是否正確標示

視覺效果測試

  • 🎨 主題切換是否有平滑的過渡效果
  • 🎨 切換提示 toast 是否顯示且自動消失
  • 🎨 各主題的配色是否符合預期
  • 🎨 文字對比度是否足夠清晰
  • 🎨 主題按鈕的視覺回饋是否明確

持久性測試

  • 💾 重新整理頁面後主題是否保持
  • 💾 關閉瀏覽器重開後設定是否保存
  • 💾 在不同網站間切換主題是否同步

⚡ 實際使用場景

🌅 白天使用

建議使用 亮色主題 或 自動適應

在明亮環境下提供最佳可讀性

🌙 夜間使用

建議使用 深色主題 減少眼部疲勞

或選擇柔和的 海洋主題

🎯 特定網站

對於特殊設計的網站，可選擇 彩色主題 配合網站風格

或使用 自動適應 讓系統智能選擇

📊 預期測試結果

✅ 主題切換操作流暢無延遲 ✅ 視覺過渡自然舒適 ✅ 快捷鍵響應正確 ✅ 主題選單操作直覺 ✅ 設定持久保存 ✅ 所有主題配色清晰可讀 ✅ Toast 提示適時顯示

如果發現任何問題，請檢查：

  • 瀏覽器控制台是否有錯誤訊息
  • Smart TOC 擴充套件是否為最新版本
  • 是否有其他擴充套件衝突

📖 測試內容章節

第一章：基本功能

這是第一章的內容，用來測試目錄的生成和主題切換效果。

1.1 主題系統架構

Smart TOC 的主題系統採用模組化設計，支援動態切換和自動適應。

1.2 使用者介面設計

介面設計遵循簡潔直覺的原則，提供多種操作方式滿足不同使用習慣。

第二章：進階功能

進階功能包括鍵盤快捷鍵、設定持久化和自動同步等特性。

2.1 快捷鍵操作

支援 Alt+T 快速切換主題，提升操作效率。

2.2 設定同步

主題設定會自動保存並在不同網頁間同步。

第三章：自訂配色

未來版本將支援使用者自訂配色方案和主題編輯功能。

3.1 配色原理

基於色彩理論和可讀性原則設計的配色方案。

3.2 個人化設定

允許使用者根據個人喜好調整主題細節。
