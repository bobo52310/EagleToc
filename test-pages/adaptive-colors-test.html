Smart TOC 自適應配色測試頁面

測試說明：這個頁面用來測試 Smart TOC 擴充套件的融合式自適應配色功能。點擊右上角的按鈕切換不同的背景主題，觀察 TOC 面板是否會自動調整為接近背景色調的配色方案，看起來更自然融合而不突兀。

1. 功能概述

Smart TOC 現在具備融合式智能配色功能，能夠：

  • 自動偵測網頁的背景顏色和色調
  • 分析背景的明暗程度和色彩特性
  • 生成與背景和諧的相近色調配色方案
  • 保持適度對比度確保可讀性
  • 讓 TOC 面板自然融入網頁視覺風格
  • 支援背景模糊效果增強層次感

2. 偵測機制

系統會按優先順序檢查以下元素的背景顏色：

2.1 主要元素

  • document.body
  • document.documentElement

2.2 內容容器

  • main 標籤
  • .content 類別
  • #content ID
  • article 標籤

2.3 特殊容器

  • .post 類別
  • .page 類別

3. 融合式配色策略

3.1 深色背景處理

當偵測到深色背景時，TOC 面板會：

  • 保持原背景色調，增加 40-60 單位亮度
  • 使用 85% 透明度創造融合感
  • 淡色文字 (#e0e0e0) 確保適度對比
  • 柔和的邊框和陰影效果
  • 添加背景模糊效果 (backdrop-filter)

3.2 淺色背景處理

當偵測到淺色背景時，TOC 面板會：

  • 保持原背景色調，減少 25-35 單位亮度
  • 使用 85% 透明度保持和諧感
  • 深色文字 (#333333) 確保可讀性
  • 自然的邊框和陰影效果
  • 添加背景模糊增強層次

3.3 彩色背景處理

當偵測到彩色背景時，系統會：

  • 保持原始色調 (Hue) 不變
  • 調整明度創造視覺層次
  • 生成同色系的和諧配色方案
  • 確保 TOC 看起來像是網頁的原生組件

4. 亮度計算

系統使用標準的相對亮度公式：

luminance = (0.299 * R + 0.587 * G + 0.114 * B) / 255

當亮度值小於 0.5 時判定為深色背景。

5. 支援的顏色格式

5.1 RGB 格式

支援 rgb(r, g, b) 和 rgba(r, g, b, a) 格式

5.2 十六進制格式

支援 #RRGGBB 六位數十六進制格式

5.3 預設處理

當背景為透明或無法偵測時，預設為白色背景處理

6. 測試指示

請使用右上角的按鈕切換不同背景主題，並觀察：

  1. 融合度測試：TOC 面板是否看起來自然融入背景
  2. 可讀性測試：文字對比度是否足夠清晰易讀
  3. 和諧性測試：配色是否與背景色調協調一致
  4. 響應性測試：切換主題時是否即時更新配色
  5. 層次感測試：背景模糊效果是否增強視覺層次
  6. 交互測試：按鈕和選項是否在各種背景下都清晰可用

6.1 重點測試場景

  • 基本色調：測試黑白灰基礎配色的適應性
  • 彩色主題：驗證彩色背景下的色調保持和明度調整
  • 特殊效果：測試漸層背景的處理能力

7. 實作細節

7.1 偵測時機

在 TOC 面板創建後立即執行背景偵測

7.2 樣式應用

使用動態創建的 style 標籤，搭配 !important 確保優先級

7.3 效能考量

只在初始化時執行一次，避免重複計算
