Smart TOC 白名單功能測試

測試域名白名單的自動載入功能

當前域名：file://
測試步驟：
  1. 點擊瀏覽器的 Smart TOC 擴充功能按鈕
  2. 點擊設定按鈕 ⚙️ 開啟設定面板
  3. 查看白名單功能區域，測試各種設定
  4. 重新載入頁面測試自動載入行為
預設白名單域名：
  • wikipedia.org - 完全匹配
  • *.wikipedia.org - 通配符匹配所有子域名
  • github.com - GitHub 主域名
  • *.github.io - GitHub Pages
  • developer.mozilla.org - MDN 文檔
  • stackoverflow.com - Stack Overflow
  • medium.com - Medium 文章
  • *.medium.com - Medium 子域名
域名匹配測試範例：
  • en.wikipedia.org → 應該匹配 *.wikipedia.org
  • zh.wikipedia.org → 應該匹配 *.wikipedia.org
  • github.com → 應該匹配 github.com
  • user.github.io → 應該匹配 *.github.io
  • blog.medium.com → 應該匹配 *.medium.com
  • example.com → 不應該匹配 (不在白名單)
  • sub.example.com → 不應該匹配 (不在白名單)

白名單功能測試項目

  1. 開關測試：
    • 白名單開啟時：只有白名單內的域名才會自動載入 TOC
    • 白名單關閉時：所有域名都會自動載入 TOC
  2. 域名匹配測試：
    • 完全匹配：github.com 只匹配 github.com
    • 通配符匹配：*.github.io 匹配所有 .github.io 子域名
  3. 管理功能測試：
    • 新增域名：輸入新域名並點擊 + 按鈕
    • 移除域名：點擊域名旁的 × 按鈕
    • 新增當前域名：點擊 "新增當前" 按鈕
    • 重置白名單：點擊 "重置預設" 按鈕

域名白名單原理說明

Smart TOC 的域名白名單功能使用以下匹配規則：

完全匹配

當白名單條目不包含通配符時，進行完全匹配。例如 github.com 只會匹配 github.com。

通配符匹配

當白名單條目以 *. 開頭時，匹配所有子域名。例如 *.wikipedia.org 會匹配：

  • en.wikipedia.org
  • zh.wikipedia.org
  • fr.wikipedia.org
  • 但不匹配 wikipedia.org 本身

Auto-show 行為

當頁面載入時，Smart TOC 會檢查：

  1. 白名單功能是否開啟
  2. 如果開啟，當前域名是否在白名單中
  3. 如果匹配成功，則自動顯示 TOC
  4. 如果白名單功能關閉，則對所有域名自動顯示 TOC
