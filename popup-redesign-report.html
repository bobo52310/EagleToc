Popup Redesign 比較報告

三種設計版本（v1/v2/v3）— 寬度更寬、RWD 友善、視覺更有質感。下方提供重點說明與截圖。
v1 • feature/popup-redesign-v1 ModernCard layoutQuick settings
  • 雙欄自適應卡片排版（≥640px 兩欄）
  • 顯眼的主要動作按鈕 + 簡潔提示
  • 快速設定：Theme、Position、Width、Font
  • 寬度：clamp(420px, 60vw, 720px)
JS 在非擴充環境啟動「Demo 模式」，避免 chrome.* API 錯誤；在擴充環境可即時寫入基礎設定。
v2 • feature/popup-redesign-v2 Side navTwo-columnRWD
  • 左側導覽／右側內容區，分類更清晰
  • 窄螢幕導覽列自動變成頂部橫向
  • 快速設定與行為控制分頁化
  • 寬度：clamp(480px, 65vw, 800px)
提供 Appearance、Behavior、Links 等分區。基礎設定同 v1 可即時寫入；非擴充環境安全退化。
v3 • feature/popup-redesign-v3 Search headerCardsWide
  • 上方搜尋列加強專業感（目前視覺用）
  • 三個快速動作卡片：TOC、Zen、Docs
  • 滑桿式快速設定（Width / Font）
  • 寬度：clamp(520px, 60vw, 760px)
Zen 透過訊息嘗試觸發（若內容腳本未掛載則略過）；支援 demo 模式避免 chrome.* API 例外。
版本比較摘要
  • 共同點：皆提供更寬視窗與 RWD；在 popup.js 中加入安全降級，方便於本地 HTML 頁面直接預覽。
  • v1：現代卡片 + 快速設定，易懂、著重主要操作。
  • v2：資訊架構更清楚的雙欄導覽，適合較多設定項。
  • v3：更有品牌感的搜尋 Header 與卡片區，視覺最「精緻」。
