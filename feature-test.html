萬用字元測試

測試萬用字元白名單功能。現在支援以下格式：

  • *.example.com - 匹配所有 example.com 的子域名
  • test.* - 匹配所有以 test 開頭的域名
  • *.github.* - 匹配包含 github 的所有域名
  • docs.*.org - 匹配 docs.任何子域名.org

工具提示測試

將滑鼠移動到 TOC 工具列上的按鈕，應該會立即顯示中文提示文字，無需等待。

設定面板測試

點擊設定按鈕開啟設定面板後，再點擊其他任何按鈕（搜尋、折疊、複製等），設定面板應該會自動關閉。

Dark Theme 測試

切換系統到深色模式，或使用開發者工具強制啟用深色模式：

document.documentElement.style.colorScheme = 'dark'

TOC 面板應該會自動切換到深色主題。
