Getting Started

To use the Smart TOC extension, simply click the extension icon in your browser toolbar. The table of contents will appear as a floating panel on the right side of the page.

Installation

You can install the Smart TOC extension from the Chrome Web Store or load it manually in developer mode.

Manual Installation

For manual installation, enable developer mode in Chrome extensions and load the unpacked extension folder.

Chrome Web Store

The extension will be available on the Chrome Web Store for easy installation.

First Use

After installation, navigate to any webpage with headings and click the Smart TOC icon to see the table of contents.

Features Overview

Smart TOC offers numerous features to enhance your reading experience on the web.

Automatic Detection

The extension uses a smart algorithm to detect the main content area and extract headings from h1 through h6 tags.

Content Area Detection

Smart TOC looks for common content containers like main, article, and various content wrapper classes.

Heading Filtering

Only visible headings with actual text content are included in the table of contents.

Interactive Navigation

Click any heading in the TOC to smoothly scroll to that section of the page.

Current Section Highlighting

As you scroll through the page, the current section is automatically highlighted in the TOC.

Smart Scrolling

The TOC automatically scrolls to keep the active heading visible within the panel.

Customization Options

The extension provides various customization options through the settings panel.

Heading Levels

Choose how many heading levels to include in the TOC (from 3 to 6 levels).

Position and Size

Drag the TOC panel to reposition it, or resize it using the drag handle in the bottom-right corner.

Auto-show

Enable auto-show to automatically display the TOC when compatible pages are loaded.

Advanced Features

Smart TOC includes several advanced features for power users.

Glance Mode

Hold the Alt/Option key and hover over any heading to quickly glance at the table of contents without permanently showing it.

Keyboard Shortcuts

Use Alt+T to toggle the TOC, or press Escape to close it when visible.

Copy Functionality

Click the copy button to copy the table of contents to your clipboard in markdown format.

Expand and Collapse

Use the expand/collapse buttons to show or hide deeper heading levels.

Dynamic Content Support

The extension automatically detects when new headings are added to the page and updates the TOC accordingly.

Single Page Applications

Works with modern SPAs that dynamically load content without page refreshes.

Progressive Web Apps

Compatible with PWAs and other dynamic web applications.

Troubleshooting

Common issues and their solutions when using Smart TOC.

No Headings Detected

If no headings are detected, ensure the page uses proper HTML heading tags (h1-h6).

Performance Issues

The extension is optimized for performance and should not impact page loading or scrolling.

Memory Usage

Smart TOC uses minimal memory and automatically cleans up when pages are closed.

CPU Usage

All operations are debounced and optimized to minimize CPU usage.
