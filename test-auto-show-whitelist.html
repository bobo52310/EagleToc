Smart TOC 白名單自動顯示功能測試

🎯 測試目標

驗證白名單網站能夠自動顯示 Smart TOC，無需用戶手動開啟。

📝 注意：已移除黑名單機制，現在純粹依據白名單控制自動顯示，邏輯更加簡潔。

🧪 測試步驟

  1. 確認當前網域：檢查這個測試頁面的域名
  2. 添加到白名單：
    • 點擊擴充套件圖示開啟 Smart TOC
    • 點擊 📌 按鈕將當前網域加入白名單
    • 確認看到「已將 xxx 加入白名單」通知
  3. 重新載入頁面：刷新頁面或重新開啟
  4. 觀察自動顯示：TOC 應該在頁面載入後自動出現
  5. 檢查 Console 日誌：查看詳細的自動顯示邏輯

✅ 成功標準

  • 自動出現：TOC 面板在頁面載入後 500ms 內自動顯示
  • 正確偵測：系統正確識別當前網域在白名單中
  • 標題檢測：至少偵測到 2 個標題（滿足最小要求）
  • 狀態通知：顯示「自動顯示」的相關通知

🔍 調試信息

如果自動顯示沒有啟動，請檢查以下 Console 日誌：

  • 🔍 Checking auto show conditions - 開始檢查條件
  • 📊 Headings count - 標題數量檢查
  • 🌐 Checking auto show for domain - 域名檢查
  • ✅ Domain is in whitelist - 白名單確認
  • ⏰ Scheduling auto show - 排程自動顯示

手動檢查指令：

// 檢查當前域名 window.location.hostname // 檢查白名單狀態 window.smartTOC.isInWhitelist(window.location.hostname) // 檢查自動顯示設定 window.smartTOC.settings.whitelistEnabled // 強制觸發自動顯示檢查 window.smartTOC.checkAutoShow()

結論

總結測試結果和觀察到的行為。

預期行為說明

🎯 白名單自動顯示邏輯 (簡化版)

簡化後的邏輯：

  1. 標題檢查：頁面必須有至少 2 個標題
  2. 白名單檢查：當前網域必須在白名單中，或手動啟用 autoShow
  3. 自動顯示：滿足條件後，在 500ms 延遲後自動顯示

🗑️ 已移除：黑名單機制（用戶手動關閉記錄），簡化為純白名單控制。

🔧 技術實作

  • checkAutoShow() - 在頁面載入完成後執行
  • shouldAutoShowBySettings() - 檢查設定和白名單
  • shouldAutoShow() - 最終決定是否顯示
  • autoShowTOC() - 執行自動顯示並顯示通知

⚙️ 設定說明

自動顯示有兩種觸發方式：

  • 全域啟用：設定中的 autoShow: true
  • 白名單啟用：網域在 autoShowWhitelist 中

這樣的設計讓用戶可以：

  • 在特定網站（白名單）啟用自動顯示
  • 或者在所有網站全域啟用
  • 同時保持對個別網站的精細控制

故障排除

如果 TOC 沒有自動顯示：

  1. 確認白名單：當前域名是否真的在白名單中？
  2. 檢查標題數量：頁面是否有至少 2 個標題？
  3. 檢查設定：whitelistEnabled 是否為 true？
  4. 檢查 Console：是否有錯誤或警告訊息？
  5. 重新載入：清除快取後重新載入頁面

✅ 邏輯簡化完成

不再需要清除黑名單！現在系統只依據白名單決定是否自動顯示，邏輯更加直觀。
